# Orbital Studios

Orbital Studios is a student-run studio that builds free websites for local nonprofits, community organizations, and small businesses.

This repo currently holds one project:

- [`agency-site/`](agency-site/) — the marketing site for Orbital Studios itself. Plain HTML/CSS/JS, no build step. See its [README](agency-site/README.md) for how to run, edit, and deploy it.
